## 🔒 Security & Trust / Seguridad y Confianza

Para proteger a la comunidad y blindar el ecosistema frente a la volatilidad del mercado, el proyecto implementa medidas estrictas de transparencia on-chain:

* 🔥 **Quema Deflacionaria:** Se ha ejecutado la quema permanente del **10% del suministro total de tokens** enviándolos a la dirección nula (`0x000...dead`), reduciendo la oferta circulante y potenciando el valor a largo plazo.
* 🛡️ **Liquidez Protegida:** Los pools de liquidez se encuentran gestionados bajo contratos auditados y optimizados para prevenir vulnerabilidades de reentrancy y manipulación de precios.
* 🌐 **Descentralización:** Arquitectura compatible con los DEXs líderes de la red BSC, operando de forma transparente y sin privilegios ocultos de acuñación (*mint*).
